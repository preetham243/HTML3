HEADINGS

Headings are used to show important text in HTML. the largest heading is h1, and smallest is h6. this diagram shows them:

Im h1. Im pretty big!

Im h2. Im slightly smaller, but still pretty big!

Im h3. Im the midpoint-neither big nor small. Im just in the middle!

Im h4. Im slightly smaller than the middle, and therfore, Im the largest of all the smallest headings!

Im h5. Im so small, that Im only one heading level above the smallest heading!
Im h6. Im the smallest heading-Im even smaller than a paragraph tag!

As you can see, hadings can range from ENOURMOUS to TEENSY WEENSY! lets learn how to use them!

<h1><h1> - this is how to use h1

<h2><h2> - this is how to use h2

<h3><h3> - this is how to use h3

<h4><h4> - this is how to use h4

<h5><h5> - this is how to use h5

<h6><h6> - this is how to use h6
